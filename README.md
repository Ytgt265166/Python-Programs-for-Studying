# Python-Programs-for-Studying
気が向いたときや勉強したくなったときにPythonコードを作って管理するリポジトリ。

## githubにコミット、プッシュする方法
1. ソース管理(上から３番目のアイコン)を開く
2. コミットしたいファイルの右側にある＋を押す
3. コミットに名前を付ける
4. コミットボタンを押す
5. 同期ボタンを押す

## githubのコードからVS codeを開く方法
https://github.com/ユーザー名/リポジトリ名をhttps://github.dev/ユーザー名/リポジトリ名に変更する
devというブラウザ版VS codeを開ける

## Github上で動かす場合
1. リポジトリ画面からCode⇒Codespaces⇒Create Codespaceで起動
2. クラウド上のVS code環境になる
3. python main.pyみたいに入力して実行
